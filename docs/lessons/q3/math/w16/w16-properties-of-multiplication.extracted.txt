Commutative Property (Order Doesn't Matter)




                                 4×5=5×4

PROPERTIES 2 & 3


Identity Rule vs. Zero Rule




      1                                                        0

    Identity Property                                        Zero Property

    7×1=7                                                    9×0=0
    Any number multiplied by 1 stays itself (Mirror Rule).   Any number multiplied by 0 becomes zero (Zap Rule).
